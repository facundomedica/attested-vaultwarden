# Release policies

One TOML file per deployed release, named `<release>.toml`, committed together
with a signed git tag `release/<release>`. The format is defined and validated
by `common/src/policy.rs`.

A policy pins:

* the platform (`tdx`, `sev-snp`);
* expected firmware/OS measurements (TDX: MRTD, RTMR0-2; SNP: launch
  measurement);
* the hash of the measured compose document (TDX/dstack: `compose_hash`;
  SNP: `host_data`, see [docs/SNP.md](../docs/SNP.md), untested on hardware);
* the allowlist of container images, each pinned by `@sha256:` digest;
* accepted TCB status and PCK platform flags (`allow_smt`,
  `allow_dynamic_platform`, `allow_cached_keys`, all default false);
* optionally the RTMR3 `app_id` and `key_provider` (D-020: these differ
  between Phala Cloud and self-hosted dstack, so each target gets its own
  policy file).

Upgrades change measurements, so every legitimate version must appear here.
A deployment whose measurements match no committed policy is, by definition,
not running published software.

document, for review. All are development releases: private sidecar image,
PCK flags SMT/dynamic platform/cached keys accepted.

## Measurement tooling

`measure/measure-tdx.sh` recomputes MRTD and RTMR0-2 from a published dstack
OS image with `dstack-mr` (built from source by `measure/Dockerfile`, no
network during the computation) and compares them with a policy.
Prerequisites for the command in each policy header:

```bash
docker build -t avw-dstack-mr:350a0a7 policy/measure   # dstack-mr at dstack 350a0a73
# the OS image from the dstack GitHub release mkosi-os-v0.6.5 (630 MB):
#   dstack-0.6.5.tar.gz, sha256 f33965e051234044b1805845b3318a92c87477b728882665cd8488d1a0d66016
```

Each policy header also names the commit the `attest` sidecar image was
built from; rebuild that commit with `attest-sidecar/reproducible-build.sh`
to check the pinned digest.

The INSECURE local mock policy is generated by `deploy/local/up.sh` into
`deploy/local/.generated/` (its sidecar digest changes on every build) and is
never committed here.
